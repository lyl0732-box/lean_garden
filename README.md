# 证明花园 · Lean Garden

本机与 Linux 云端运行、以卡牌按钮为主的 Lean 4 证明冒险游戏。`use` 的见证由玩家手动填写，每一步由真实 Lean 内核验证。当前默认发行 **0.13.4 无广告、无现金内购版**，包括 Windows、直发 Android 和网页版。TapTap 走独立打包流程。用户管理见 [控制室使用说明](docs/服务器监控与用户管理.md)，历史修改文档存放在 `revisions/`。

## 从 GitHub 首次运行

仓库保存源码和原始图片／音乐，约 117 MB；不包含依赖、Mathlib 缓存、生成的高低清晰度资源、安装包、玩家数据库或私钥。以下步骤在 Windows PowerShell 中执行，需要 Node.js 22+、elan／Lean 与网络；`lean/lean-toolchain` 固定编译器版本。

```powershell
git clone git@github.com:lyl0732-box/lean_garden.git
cd lean_garden
npm ci
npm run build:assets
.\setup.ps1
npm start
```

随后打开 **http://localhost:3210**，注册自己的账号。首次构建会重新生成 `public/assets/optimized/`、资源清单和 `clients/bundled/`；安装 Lean / Mathlib 首次需要下载较大依赖，不能用 `build:manifest` 代替首次素材构建。已有素材时才使用 `npm run build:manifest` 做快速更新。GitHub 上没有作者本机和云端的账号或成绩，新环境从空数据库开始。

Windows 客户端另执行 `npm ci --prefix clients/windows` 和 `npm run build:windows`。Android 工程位于 `clients/android/`，需要 JDK 21、Android SDK 36、Gradle 8.11.1 及自己的签名配置；作者本机的 SDK 路径和签名密钥不随仓库分发，具体见 [源码与构建说明](docs/GITHUB.md)。

分析 BOSS 的完整命题：若 `f` 在 `[0,1]` 连续、在 `(0,1)` 可导，且 `f(0)=0`、`f(1)=1`，证明存在 `0<u<v<1`，使 `f′(u)f′(v)=1`。先通过介值定理得到 `f(c)=1−c` 的辅助点，再分别在 `[0,c]` 和 `[c,1]` 应用中值定理。

数论 BOSS 从 `gcd(m,n)=1` 得到裴蜀系数，构造 `x=a(nv)+b(mu)`，分别给出两个整除见证。没有直接调用库里的中国剩余定理来跳过构造。

## 启动与停止

```powershell
# Node 绑定本机，服务隐藏运行；已配置的 Tailscale 转发独立运行
.\start.ps1

# 也可以在当前终端运行，Ctrl+C 停止
npm start

# 停止由 start.ps1 启动的服务
.\stop.ps1
```

`start.cmd` 会启动服务并打开浏览器。`stop.cmd` 会核对服务 PID 与程序路径，只停止本项目服务。

如以后需要在同一 Wi-Fi 下用手机试玩，先停止当前服务，再运行：

```powershell
.\stop.ps1
.\start.ps1 -Lan
```

终端会打印本机局域网地址。手机打开该地址；电脑须保持开机，手机和电脑须处于可以互相访问的局域网。脚本不会修改 Windows 防火墙；若系统阻止连接，需要在私有网络下允许 Node。默认启动不开放局域网。

## 环境

- Node.js 22 或更新版本。运行时不需要安装 npm 依赖。
- Lean **4.34.0**，由 `lean/lean-toolchain` 固定。
- Mathlib **v4.34.0**，提交及依赖由 `lean/lake-manifest.json` 固定。
- 本机原来只有 Lean 和一个不含 Mathlib 的测试项目；本次在本项目的 `lean/.lake/` 中安装了匹配版本的 Mathlib 及编译缓存。

作者本机环境已经准备完成。通过 Git 克隆到其它电脑时，按文首步骤构建素材并运行 `setup.ps1`。首次下载 Mathlib 需要网络和较多磁盘空间；准备好后，本地游玩只访问本机。

客户端提交关卡 ID、卡牌 ID，或仓库条目 ID、方向与命题位置。服务端根据已解锁的白名单定理和实际 Lean 上下文生成源码，不接受浏览器传入的任意 Lean 或命令。玩家可以选择不同于参考解的合法证明；指定教学关还须完成要求的定理改写。成功标准是 Lean 返回零个剩余目标、编译退出码为零，且没有未完成证明警告。失败的出招不会记入证明序列。

本次升级前的备份为 `data/progress.before-v010.json`，以前各版备份保留。v0.10.0 增加经济系统版本 1，导出格式升为 8；保持证明规则版本 4 和课程迁移标记 9。旧存档按已有成绩补计成长经验，不清除原有关卡、星星和证明。v0.9 第九关的旧尝试与成绩快照仍保留在 `legacyLevelsV8.n06`，v0.7 的旧小游戏归档仍保留在 `legacyChallengesV6.m02`。此前升级 v0.4 的历史兼容说明见 [v0.4 文档](docs/VERSION-0.4.md#存档兼容)。

进度按登录账号保存在服务器。清除浏览器 Cookie 后重新登录同一账号可以继续。不同服务器的数据库相互独立，GitHub 只保存代码。设置中的导出是备份功能，整机恢复需停服并同时保留 `data/accounts.json` 和 `data/progress.json`。
