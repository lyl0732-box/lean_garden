# 0.4 · 页游更新（2026-10-28）

## 0.4.1 · 提示与续玩

- 提示不再把长 Lean 命令当作按钮说明：先给思路，再列出技能、作用位置、改写方向和证据分类。可以准备参数，确认仍由玩家操作。参考路线以外的合法证明不被覆盖。
- 补充高级关卡的中文操作名称。归纳分支用「起点」和「下一步」解释，可预览等待分支的已知条件和目标，当前证明顺序保持不变。
- 对局可免费查看当前数学符号的解释；随身卡册按技能、定义、定理、公理展示已发现的知识。
- 地址记录关卡或章节；刷新恢复证明，浏览器前进、后退恢复相应页面。首页继续最近尚未完成的冒险。导航失败后可以重试。
- 课程仍为 113 关，原有关卡、证明规则、奖励归属和历史存档保持兼容，无需重置。
- 验证覆盖 218 个真实 Lean 状态中的提示参数，另有课程/教学测试和手机、桌面浏览器验证。浏览器报告见 `artifacts/learning-ui-report.json`。

本轮只完善本地页游。桌面版、Steam、小程序发布和客户端 Lean 引擎尚未开展，`下一步计划.txt` 保持原样。

## 游玩变化

- 首页只有一套冒险、小游戏、禅净花园入口，另有选关与重置。新增花园大门转场。
- 七个音乐场景：主页、选关/小游戏、禅净花园、自然数/逻辑/分析/数论正赛。全曲本地循环，切换淡入淡出；卡片绽放配四次钟鸣和收尾和弦。
- 技能绿色、定义蓝色、定理紫色、公理橙色。花园分四类，未知卡只显示 `⊘`。仓库把已有命题与三类规则分开，并显示公式。
- rw 方向、次数使用单选按钮；选定证据后在主界面查看实际匹配位置，可复选多处。按编号从后往前改写；任何一步失败都会保留原证明。
- 默认只改第一处，repeat 才反复改写。改写不自动收尾。`rfl` 只接受两侧写法相同的等式；`add_succ` 不会把 `+1` 偷换为 `succ 0`。
- 后继、加法等主题使用庆祝彩蛋，不再发放重复的概述定义卡。加法的定义卡就是 `add_zero`、`add_succ`。
- 定理卡由对应证明的通关记录解锁。交换律等关卡不能提前选用自己的结论。

## 课程

原有 97 关的题目与 ID 全部保留，新增 16 关，共 113 关：自然数 32、逻辑 25、实分析 29、数论 21、小游戏 6。共有 87 张可收集卡，公理类仅包含五条皮亚诺规则。

自然数开篇顺序：

1. `0 = 0`
2. 用假设改写
3. `succ 0 = 1`
4. 数字 2、3、4 的定义接力
5. 加零定义
6. 加后继定义（保留原关）
7. `1 + 1 = 2`
8. 假设与加零综合运用（保留原关）
9. 证明 `add_one_eq_succ`
10. `2 + 2 = 4`
11. 归纳证明 `zero_add`，精英守卫

归纳、结合律、交换律等较长证明采用独立的首领徽章。新增的高级证明工坊安排在应用题之前；高级课程仍调用 Mathlib 中的基础分析、拓扑和欧几里得算法结果，并非重建整套数学库。
