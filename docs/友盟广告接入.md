## 还需填写的后台配置

在 U-AppWin 后台找到广告位 `100015016`，设置服务端奖励验证。

- 回调地址：`https://162.14.77.140/api/ads/appwin/reward`
- `appSecurityKey`：采用该广告位的服务端验证密钥，不能使用 AppKey 或广告位 ID 代替。
- 本机密钥文件：`deploy/.private/appwin-security-key.txt`，仅包含密钥本身。
- 云端密钥文件：`/home/ubuntu/lean-garden/data/appwin-security-key.txt`，文件权限应为 `600`，所有者为运行游戏服务的用户。
- 也可配置 `GARDEN_APPWIN_SECURITY_KEY_FILE` 指向私密文件；`GARDEN_APPWIN_SECURITY_KEY` 环境变量也受支持。

密钥文件准备好后，双击项目根目录的 `配置广告奖励.cmd`，它会通过 SSH 安全地把密钥写入云端私密文件，并重启游戏服务；密钥不会出现在命令参数或输出中。普通的 `推送到服务器.cmd` 只更新代码，不会传本机私密目录或覆盖云端密钥、玩家进度和广告奖励记录。

用户随后提供了广告位的 `secureKey`，已按服务端验证密钥保存到本机私密文件，并通过 SSH 配置到云端，游戏服务已重启。密钥未写入本文、安装包或输出日志。服务器奖励验证已配置；广告平台后台仍需保存上面的回调地址，真实平台回调与奖励到账由用户自行测试。以后缺少密钥时，服务器仍会将奖励广告标记为“配置中”。

服务端接口和游戏页面已发布到公网服务器，版本为 0.12.3。后台保存回调地址后，完全退出并重新进入新版安卓游戏，即可由用户自行测试。

官方回调文档建议使用 HTTPS 域名，并提示 IP 地址可能收不到回调。上面的 IP 地址可先用于配置尝试；若后台拒绝该地址或平台无法回调，需要换成指向此服务器的 HTTPS 域名。域名的路径仍为 `/api/ads/appwin/reward`。

## 奖励如何到账

服务器为每次观看生成随机会话，把会话标识作为 SDK 的 `userId` 和 `customData` 传入。SDK 播放结束或互动完成时产生奖励回调；真正的钻石和活跃度由服务器在收到友盟回调、核验 `sha256(appSecurityKey:transId)` 后发放。

每次有效广告获得 50 钻石，活跃度入口还会恢复满 50 活跃度；每天合计最多 10 次。提前退出和加载失败不扣领取次数。客户端的 `valid: true`、伪造完成请求或重复通知都不能额外领奖。回调可在客户端关闭后独立到账，回到游戏时会同步余额。

`data/appwin-rewards.json` 保存广告会话和交易的对应关系，`progress.json` 保存实际余额和已领取交易；双方都沿用服务器数据目录，部署时不会用本机数据替换。验证密钥不进入 APK、浏览器、存档导出或日志。
