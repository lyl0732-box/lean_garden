# 下一步计划 9 · v0.13.0

本轮保留所有原有关卡与玩家存档。清单中已经完成的用户管理和默认服务器地址继续保留。

| 清单项 | 修改结果 |
| --- | --- |
| 1 · 七天签到 | 主页礼物按钮和设置可进入。按服务器北京时间每天领取一次；依次为 30 钻、5 提示、50 钻、1 答案、1 免广告券、2 答案、300 钻。漏签重置，七天后重新循环。按账号持久保存，重复请求、重置冒险和换设备不能重复领取当天奖励。 |
| 3 · 作者及教程 | 设置和冒险选关页显示微信／手机号与 B 站入门教程链接。 |
| 8 · 安卓安装包更新 | 原生登录页显示实际安装版本；登录页与游戏设置的检查更新均支持完整 APK。下载后验证大小、SHA-256、包名、版本和原签名，再打开系统安装器。允许同版重新安装，拒绝降级；首次需在系统中允许此来源安装。资源同步保留，不能替代原生安装包更新。 |
| 9 · 定义卡 | 保留原 `pow` 卡 ID，改成仅含零次方定义；增加独立 `pow_succ` 蓝色定义卡和台阶插图。绝对值的正负两种展开、开闭区间也拆为独立卡片；余数卡保留一个例子。旧通关及证明保留。 |
| 10 · 交换律及代码 | 仓库中只保留一张通用加法交换律；第 18 关参考证明改为指定第 2 处。翻转界面按钮循环“全部代换 → 指定位置 → 精细代码修改”。代码框支持当前卡片的 `rw`、`nth_rewrite`、`repeat' rw`、反向、当前变量参数与 `at`；经过受限语法解析后交给 Lean，不开放任意命令。 |
| 11 · 自由选关到期 | 到期自动回到正常冒险地图，关闭自由模式，保留练习。后端对过期请求、持续提交及编译跨过到期时间再次拦截。管理员保持无限选关。 |
| 12 · 手机顶部蓝边 | 移除对战前的倒计时占位，将剩余时间放进对战内部；背景从视口顶部开始，刘海区域由原生安全区保护控件。 |

安装新版安卓 APK 后，后续可以从客户端检查并安装新版本。旧客户端首次需要手动覆盖安装；不能通过资源更新获得尚不存在的原生安装器。

验证记录见 `artifacts/final-verification.json`、`artifacts/repository-verification.json`、`artifacts/plan9-retest.log` 与 `artifacts/plan9-browser-report.json`。安卓构建和原签名校验完成。真实手机上的系统授权、下载安装体验与广告播放仍留给作者操作，本轮没有自动播放广告或模拟崩溃。

以后更改安卓版本：修改 `clients/android/app/build.gradle` 中的 `versionCode`（递增）及 `versionName`，原生登录页和客户端标识会自动读取版本。重新执行 `npm run build:manifest`、`npm run build:android`，再执行 `推送到服务器.cmd`。构建会生成 `public/android-release.json` 并把 APK 放入 `public/downloads`；推送脚本会校验并上传对应安装包。服务器玩家数据及广告密钥不在上传范围。
