# 卡牌美术

`public/assets/cards/` 中的插图由本项目代码绘制，延续现有圆润、植物与绘本风格。没有复制其他游戏的角色或素材。每个当前使用的定理、定义和技能都有独立场景，仓库、图鉴、温习、左侧技能栏和通关奖励共用同一张图，帮助形成视觉记忆。

- `one_eq_succ_zero`：新芽踏上零之后第一格。
- `add_zero`：右边空篮子不改变左边果子。
- `add_succ`：藤蔓队伍多走一格。
- `add_one_eq_succ`：小兔跳上一级台阶。
- `add_assoc`：三种果子重新分组。
- `add_comm`：红黄花交换位置。
- `rolle` / `mvt`：同高山峰的水平位置 / 曲线与平行斜坡。
- `crt`：两把余数钥匙打开同一个宝箱。

`manifest.json` 记录每幅图的路径与中文含义。`public/card-art.js` 输出带替代文本的图片元素；SVG 画布为 240 × 180，可在不同屏幕清晰缩放。

重新生成：`node scripts/generate-card-art.mjs`。生成器同时维护 SVG、清单和前端模块。当前共 79 幅（76 张课程卡、一个兜底图和两个不再展示的旧技能图）。
