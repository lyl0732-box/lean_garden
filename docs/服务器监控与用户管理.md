# 本机监控与用户管理

在项目根目录双击 **`管理用户与监控服务器.cmd`**。会打开浏览器控制室；本机 Node 进程隐藏运行，默认地址 `http://127.0.0.1:3218/`。首次请通过启动脚本进入，它会附带当前面板的管理凭据。重复双击会打开已有面板。

项目可以整体移动到其他目录或磁盘。移动后请从新目录重新双击启动脚本：它会识别并重启仍指向旧目录的本机监控进程，同时修复 SSH 私钥因跨盘移动而继承的权限。私钥仅允许当前 Windows 用户访问，无需重新生成或更换服务器密钥。重启后，已打开的旧面板也需通过启动脚本重新进入。

管理对象是 **https://162.14.77.140/** 对应的云端服务。使用 `deploy/linux-target.json`、`deploy/.private/deploy-key.pem` 和固定主机指纹，通过 SSH 连接；不需要再输入游戏管理员密码。不对公网开放管理端口。

## 可以做什么

- 每 3 秒刷新注册账号总数、在线用户数、整台服务器 CPU 总占用、内存占用与走势图，并显示游戏进程内存。
- 搜索用户名或用户 ID，切换全部用户、仅看在线。在线按账号去重；多窗口显示窗口数。
- 点击用户后修改钻石、免广告券、提示、答案包、活跃度、芽芽经验、剩余选关分钟，以及礼包领取状态。只保存修改过的参数；不重置通关和证明记录。
- 授予或取消管理员。管理员拥有无限钻石、免广告券、提示、答案、选关时间，进入关卡不消耗活跃度；储存的普通资源仍保留。管理员也不能把现金专购的免广告券改成钻石购买。
- 重设用户密码，自动生成新的 scrypt 盐与密码哈希，同时撤销该用户全部普通登录和免密登录凭据，清空原密码提示。密码不会写入管理操作日志。

## 统计口径

注册账号总数不包含历史未绑定账号的访客存档。

游戏在前台每 20 秒发送心跳，切到后台或关闭页面时发送离线通知；断网或进程被强制关闭则最迟 75 秒后离线。多设备同一账号只计一位在线用户。已登录但没有打开游戏、停在原生连接页的用户不计在线。功能上线前已经打开的旧页面需重新加载才能开始心跳。

CPU 为全部核心合计的 0–100% 使用率，首个采样显示“采样中”。Linux 内存使用 `(MemTotal - MemAvailable) / MemTotal`，可回收缓存不当成不可用内存；与 `free` 的可用内存口径对应。

管理员权限在服务器立即更新，游戏前台在下一次心跳或操作时同步显示。密码被重设后，旧会话下一次请求会要求重新登录。

## 保存与连接

管理请求进入**正在运行的游戏进程**，使用与正常游戏操作相同的存档锁和保存队列。不会在游戏运行时从外部修改 `progress.json`。如果玩家在编辑期间花掉资源，保存会提示背包有变化；点击“刷新此用户”后重新填写，避免覆盖玩家刚做的操作。

服务端私有 Unix socket：`/home/ubuntu/lean-garden/data/admin.sock`，仅服务属主可访问（0600）。随游戏服务启动，不需要新开防火墙端口。管理操作日志：`/home/ubuntu/lean-garden/data/admin-audit.jsonl`。

SSH 中断时面板保留最后一组数据并提示离线，自动重试；未收到保存成功提示的操作，请刷新用户后核实，尤其不要因为断线反复增加资源。

双击 **`停止服务器监控.cmd`** 只停止本机监控进程，云端游戏继续运行。浏览器窗口关闭不会停止后台监控进程。

本机日志：`logs/admin-console.log`、`logs/admin-console.error.log`。`deploy/.private/admin-console-runtime.json` 是本次启动的本机访问凭据，不应分享；整个 `.private` 目录均不进入游戏安装包和推送包。

## iOS 与客户端地址

本次按用户决定暂缓 iOS 安装包。当前 Windows 环境没有 Xcode 和 Apple 签名配置，未生成可安装的 IPA。

Windows、Android 0.12.1 新安装的连接页默认填写 **`https://162.14.77.140/`**；连接时内部统一成同源地址，避免双斜杠。已有用户手动保存的其他服务器仍保留。
