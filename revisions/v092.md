# v0.9.2 · 安卓刘海白边、全屏按钮与默认最高画质

日期：2026-11-02。依据 [白边反馈](../任务清单/白边反馈.jpg)及本轮反馈修改。

## 安卓顶部白边

原生容器原来把刘海高度设置成整个 WebView 的顶部 padding，露出了浅色容器背景，与截图中的顶部色带一致。本版允许窗口绘制到刘海区域，WebView 保持从屏幕顶部铺满；只在网页操作内容和原生连接页控件上避让刘海。

Android 9／10 设置 `SHORT_EDGES`，Android 11 以上设置 `ALWAYS`；透明系统栏、保留沉浸模式。原生将安全区域尺寸换算成 CSS 像素，页面背景不下移，首页工具栏、关卡标题、模式导航及弹窗的操作内容保留安全距离。键盘高度单独处理，避免把刘海留白再次加到整个游戏上。

安卓版移除网页全屏按钮，并收回该按钮原先预留的横向空间；应用继续默认沉浸全屏。普通 Android 浏览器仍保留网页全屏按钮。

## Windows 全屏

原按钮仅检查 `document.fullscreenElement`，无法识别客户端启动时的原生全屏。本版按钮通过专用接口读取与切换 `BrowserWindow` 全屏；原生进入／退出事件同步更新按钮。

接口只开放全屏状态、切换和状态通知；主进程核验调用来自当前窗口的可信主框架，继续隔离 Node、文件和连接配置。按钮、F11／菜单与刷新后的显示使用同一个窗口状态。

## 清晰度

- 网页、Windows 与 Android 新用户均默认最高画质，弱网、省流检测不会自动降档；下载失败也不会自行换成流畅。
- 下拉框只保留「清晰画面（最高）」和「流畅省流」，卡顿时由玩家手动调整。
- 旧的「自动」配置映射为最高档；已经手动选择流畅的偏好继续保留。
- 加载中切换、设置中应用、连接页同步与进度保持沿用上一版。
