# v0.10.0 · 下一步计划 6

## 四项修改

1. 第十二关抽卡仓库把 `Nat.succ_ne_zero n` 与通用形式合并成同一张「零不是后继」公理卡。仓库不再重复显示；已用真实 Lean 验证通用形式仍能完成本关。
2. 主页入口标题不换行，并按文字区域宽度缩放字号；副标题超出时省略。手机、平板横竖屏保持固定主页。覆盖 800×1280、1280×800、600×960、390×844、844×390 的 Android 客户端 UA 浏览器测试。
3. Windows／Android 安装包内置两档画质的插图、全部知识卡、七首 BGM 和界面代码。连接时先取得小资源清单，逐个对比 SHA-256，只下载新增或变更文件。更新保存在应用私有目录，后续连接复用；全部校验通过后才启用本次版本。校验失败停在连接页重试，避免混用不同版本。真实 Lean 和存档接口仍在服务器。
4. 新增活跃度、提示／答案／免广告券背包、主页商城角标、经验和芽芽成长。按照本次用户确认，**商城只展示价格，真实支付接入后才开放购买**；没有开启内测模拟购买。免费免广告券可正常领取。

## 活跃度与物品规则

- 初始／上限 50 活跃度。每局 5 点，每 5 分钟恢复 1 点；离线经过的时间也计入恢复。满值后不囤积额外恢复时间。
- 首次进入未完成的一局扣费；刷新、重连、继续同一局、未完成时回到起点均不重复扣费。完成后点「重来」开启新局，再扣 5 点。撤销已完成的一步再收尾不重复发经验。
- 初始提示 5 次、答案包 0 张、免广告券 0 张。每点一次提示消耗 1 次，包括「再具体一点」。符号说明、知识卡册、新手教程仍免费。
- 一张答案包打开本局完整参考证明；本局可以反复查看，仍须亲手出招。未完成时回到起点保留本局答案权限和一星限制；完成后重开则属于新局。
- 提示包 ¥1／10 次；首充礼包 ¥6／10 张答案包、每份存档限一次；免广告券 ¥1／10 张。普通答案包的其他档位没有擅自定价。
- 内测见面礼每份存档免费领一次 10 张免广告券。一张券跳过广告并恢复满 50 点；已满时不会消耗券。广告 SDK 尚未接入，界面明确提示内测免费领券。
- 普通关通关 +100 EXP、小首领 +200、章节守卫 +400；重玩也奖励，每局仅一次。升级所需经验逐渐增加；每升一级花瓣、颜色或装饰改变，之后出现花冠和羽翼，主页可预览成长路线。
- 主线与自由练习共用活跃度、背包和经验，证明成绩依旧分开。重置冒险保留背包、等级和礼包领取记录。旧存档不清空，按已有通关记录补计经验；旧关卡证明和星星保留。
- 当前仍以浏览器／客户端 Cookie 标识本机存档，没有新增跨设备账户登录。清除应用数据／Cookie 会产生新存档；保留原 Cookie 才能继续原记录。

## 更新与集成

新增 `public/client-manifest.json`、`scripts/build-client-assets.mjs`。`npm run build:manifest` 同时更新网页预加载清单和客户端清单；发布新界面代码后必须重新生成这两份清单。每个资源使用内容哈希保存，不能直接替换清单而不上传对应文件。服务端源码包已包含该资源清单。

本次原生资源读取和更新器需要先安装一次 v0.10.0；之后普通界面、美术、音乐、题库及服务器规则更新无需反复安装。原生容器、系统权限或广告 SDK 等变化仍需要新版安装包。服务器必须在线以检查更新和验证证明；本次没有把 Lean 塞进客户端。

`server/commerce.mjs` 导出 `configureCommerce({payments,ads})`：支付适配器须返回经服务商核验的唯一收据，广告适配器须核验带签名的奖励凭证。服务器独占锁下发货，重复订单／奖励不再发放。默认关闭支付，未配置广告时奖励接口拒绝伪造凭据。测试环境可显式设置 `GARDEN_PAYMENT_MODE=test` 验证物品到账，正式运行不要设置该值。当前部署未设置。

主要接口：`GET /api/economy`、`POST /api/shop/claim-beta`、`POST /api/shop/purchase`、`POST /api/energy/refill`、`POST /api/energy/ad/start`、`POST /api/energy/ad/complete`、`POST /api/level/answer`。广告启动后前端派发 `garden:reward-ad`，供之后的 SDK 集成使用；完成时必须提交服务商凭据到服务器核验。

存档增加独立 `economy.version=1`，课程版本和严格证明规则保持原值；导出格式升为 8，并包含经济系统记录。升级前备份位于 `artifacts/plan6-before-20261104-095321/progress.json`，上线前另存 `data/progress.before-v010.json`。

资源读取实现参考 [Electron protocol](https://www.electronjs.org/docs/latest/api/protocol) 与 [Android WebViewClient](https://developer.android.com/reference/android/webkit/WebViewClient) 官方接口。没有向网页开放 Node 或文件系统接口。
