# v0.8 · 下一步计划 4

更新日期：2026-11-02。对应 [下一步计划4.txt](../任务清单/下一步计划4.txt) 的三项要求，并加入本轮确认的第三关翻面教学。

## 每个教学阶段都等待两秒

前三关的初始引导，以及点技能、选择类别、抽卡、翻面、确认、点选目标后的后续引导，都使用同一个 2000 毫秒延迟。有效点击先淡出旧蒙版，等待后再渐入新焦点；Lean 核验后自动切换的教学步骤也遵守该延迟。等待期间不能提前点击下一教学操作，全屏按钮仍可使用。

## 默认打开仓库里的定理分类

点击 rw 或 apply 后直接展示仓库里的「定理」分类，沿用原来的四个分类标签和卡轮。即使暂时没有可用定理，也停留在定理组，显示原有的空卡组说明。

第二关解释四类证据的用途，并引导玩家从「定理」手动切换到「已知命题」寻找 h；第三关引导切换到「定义」寻找数字 1 的定义。教程期间，鼠标和键盘都不能跳过切换步骤或点入错误类别。「帮我选好这一步」仍按明确的提示准备参数。

## 第三关亲手翻转并使用反向规则

抽出数字 1 的定义后，先引导玩家点击「反向」翻到卡片背面。正面为 `1 = succ 0`，反面为 `succ 0 = 1`。确认后点选目标，用 `succ 0 → 1` 将 `1 = succ 0` 改写成 `1 = 1`，再亲手点 rfl 收尾。

翻面、确认与选目标之间同样分别等待两秒，再显示下一蒙版。第二关仍使用正向规则，便于对比方向。

## 从芽芽杖尖发出的彩色法链

定义、定理、公理分别使用蓝色、紫色、金色法链：先从芽芽杖尖连接召唤出的知识卡，再连接实际作用命题。每帧跟随挥动中的杖尖和移动中的卡片，避免法链悬空。

保留定义水流、定理爆弹、公理金光的命中效果，以及定理和公理的震屏。已知命题继续使用经过证据位置折射的绿色闪电。关闭动画或启用系统减少动态效果时，不生成施法动画。

## 存档与使用

本轮修改界面与教程，不涉及关卡、证明规则或存档迁移。已有成绩、解锁、进行中的证明与教程完成记录继续使用；导出格式仍为 7，数据库结构仍为 1，证明规则仍为 4。已完成教程的玩家可在关卡右上角点击「教学」重看。

正式服务仍为 http://localhost:3210。静态文件使用 no-cache；刷新页面即可加载更新。
