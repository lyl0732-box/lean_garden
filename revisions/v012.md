# v0.12.0 · 下一步计划 8

1. 手机竖屏的三扇模式门铺满可用宽度。左下方只留小芽芽，点它查看当前等级和经验；商城放进下方工具区，重置进度仍在设置中。主页继续固定在视口内。
2. 施法准备、实际出招和归纳变量选择都使用账号当前的芽芽形态。八种形态共用同一份资源映射，随阶段增加杖尖光晕、光束粗细、轨道和粒子，保留关闭动画与减少动态效果设置。
3. 只有主动开启的前三关教程显示小课堂。其余对局不再免费显示课堂解法和目标下的黄色改写顺序；严格证明检查继续生效。
4. 服务端根据真实管理员角色开放无限提示、答案、钻石、免广告券及自由选关时长；界面显示 ∞。不修改真实库存，不接受客户端自报管理员。普通账号、现金券 ¥2／10 张及支付待接入规则保留。
5. 三端登录界面提供检查更新。原生客户端校验并缓存服务器变动资源；网页版核对版本并可重新加载。未登录也能检查资源更新。
6. 网页和 Windows 登录页提供全屏切换与退出；安卓继续沉浸全屏，按此前要求不显示无效全屏按钮。登录页使用花园背景，安卓增加圆角登录面板与独立输入框。
7. Windows 通过系统 DPAPI 的 Electron safeStorage 加密保存勾选后的密码；安卓使用 Android Keystore AES-GCM，绑定服务器地址和用户名。取消勾选清除保存项。网页保存 30 天可撤销的 HttpOnly 随机凭据，服务器只保存其哈希；退出后可点“免输密码登录”，不把明文密码存到 localStorage。
8. Linux 服务器已运行真实 Node 22 与 Lean 4.34.0。首次迁移保留 2 个账号、40 个历史存档和 65 条已完成证明；本机原数据保留。以后双击项目根目录的 `推送到服务器.cmd`，只传变动文件，不覆盖云端玩家数据。

公网入口：[https://162.14.77.140](https://162.14.77.140)，已配置独立证书与自动续期。部署结构和维护方法见 [Linux 运行说明](../docs/LINUX-LIVE.md)。新原生登录功能需要覆盖安装 v0.12.0；网页刷新即可。
