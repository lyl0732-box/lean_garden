# v0.7 · 下一步计划 3

更新日期：2026-10-30—31。对应 [下一步计划3.txt](../任务清单/下一步计划3.txt) 全部 15 个实际条目，并纳入随后提出的教程对白、逐次渐变蒙版、翻牌滚动和平板主页修复。仍为本机网页游戏；保留 113 个关卡 ID，只替换指定的重复小游戏。

## 抽卡：转轮与四类入口

- 定理、公理、定义、已知命题直接并排选择，移除「已有命题 / 定理仓库」的额外层级。
- 每类共用五张卡的转轮：中央最大，上下各两张，越远越小；短卡组和边缘只展示实际存在的卡，不复制卡片补位。
- 鼠标滚轮、触摸拖动、上下按钮和方向键均能拨轮，伴随机械棘轮音效与鼓轮旋转。Home / End 可到首尾，每类保留自己的位置。
- 中央卡和下方说明同时显示名称、Lean 名称及完整公式；带参数的已知命题实例也有对应公式。拨动和抽卡不提交证明。

## 翻转：全屏舞台与音效

- 准备阶段在模糊的全屏背景上展示卡片、方向、替换位置与确认按钮。卡片周围有旋转光束和呼吸光晕。
- 正反面以 3D 翻转连接，反面更深、显示反向公式，正反方向有配套翻面音效。`apply` 使用证据结论，不显示无关的翻转和改写次数。
- 桌面为卡片与参数左右两列，手机为上下排列。位置复选框更新参数时保留当前弹窗，避免整块背景闪烁。
- 光效放入独立裁切层，不参与内容高度；准备弹窗隐藏滚动条，裁掉光芒产生的空白尾部。小屏内容较长时仍能触摸滚动到实际按钮。

## 芽芽：准备、表情与施法

- 举杖时环形光晕与光点向杖尖聚集；平时有眨眼、呼吸和芽叶摆动。
- 施法期间收起主界面待命角色，只保留一个施法角色，修复大小芽芽叠加。
- 角色身体前倾、挥动魔杖，表情切换为奋力的 `>_<`，随后恢复。
- 定理与公理命中产生震屏；定义与已知命题不震屏。原来的紫色爆弹、金光、水流与闪电链继续作用于实际命题位置。
- 音效开关、动画开关及系统「减少动态效果」继续生效。

## 前三关：逐次渐变蒙版教学

- 每次进入教程关先留一秒看题，再渐入半透明蒙版，突出唯一的教学操作。点击其它按钮或用键盘绕过会被拦截；全屏按钮始终可以使用。
- **每一次有效教学点击都重新渐变**：旧蒙版淡出，再渐入新步骤的焦点，覆盖点技能、抽卡、确认、点目标及收尾，绝非仅首次进关播放一次。
- 芽芽头像和对白固定在左下角，不再跟随当前按钮移动。窄屏会把题目目标移到对白上方；弹窗也预留对白空间，避免盖住操作。
- 第一关解释 `rfl`；第二关引导使用已知 `h`；第三关引导使用 `one_eq_succ_zero`。改写后仍由玩家点 `rfl` 收尾，不自动完成证明。
- 教学状态按 v7 单独保存，不被旧版「已看教程」误跳过。自由练习不默认强制教程；主动重看会重开当前证明，保留成绩和已获知识。
- 进入时有未领礼物则先引导领取；历史证明走到不适合教学的中途时，引导重开当前证明，不让玩家卡在无法使用的 `rfl` 上。

## 全屏、归纳与地图

- 独立全屏按钮贯穿序章、主页、模式、对局、抽卡、奖励和教学；调用浏览器原生全屏 API，原生退出时同步按钮状态。浏览器不支持时给出明确提示。
- `induction` 改为模糊背景上的变量卡选择，展示实际自然数变量和「0 起点 / succ 后继」分支预览，确认后才提交归纳，不再使用下拉框。
- 选关的章节标志、完成数量和说明分占网格位置，窄屏不再重叠。
- 主页按视口高度排版，手机和平板横竖屏均固定一屏，保留三个入口、自由选关、重置与章节进度。滚轮和触摸不能把主页上下拖动；地图、花园和证明内容仍可正常滚动。

## 小游戏第二关与音乐

原重复的 m02 更换为 **双生数列塔**：已知两条从零开始的递推数列，一条逐层增加自然数，另一条逐层增加奇数，证明 `2 * f n = n * (n + 1) ∧ g n = n * n`。参考解包含联合归纳、拆开归纳假设、展开递推、后继与加一转换、拆分结论及代数收尾，共 15 步。需要对应技能已经解锁；没有提前赠送结论定理。原冒险关卡未删减，归纳教学仍在新增过渡关之后的第十一关。

逻辑章节音乐换为 Kevin MacLeod 的 **Adventures in Adventureland**，采用更轻快的奇幻探索配器。原版 MP3 已存本机，七个场景继续各有自己的曲目，切换淡入淡出。设置署名、文件清单和授权同步更新；旧曲保留并继续署名。详见 [音乐说明](../docs/MUSIC.md) 与 [LICENSE.txt](../public/assets/audio/LICENSE.txt)。拨轮、翻面及魔法音效由 Web Audio 合成，不需要联网下载。
